3. 核心改造原则

原则 1：UI 不再依赖 scrollY

❌ 错误：

onScroll(scrollY) {
   avatar.setScale(...)
}

✅ 正确：

p = scrollY / collapseDistance
update(p)

---

原则 2：Header 必须独立

❌ 不允许：

- header 在 RecyclerView
- header 在 adapter

✅ 必须：

- 独立 View Layer
- 独立 Controller

---

原则 3：UI = f(p)

所有 UI 变化统一：

UI(p)

---

4. 核心数学模型（必须统一）

4.1 progress

p = clamp(scrollY / collapseDistance, 0f, 1f)

---

4.2 easing

easeOutCubic(x) = 1 - (1 - x)^3

smoothstep(x) = x*x*(3 - 2*x)

---

4.3 avatar transform

scale = 1 - 0.35 * easeOut(p)
y     = -120dp * easeOut(p)

---

4.4 title transform

alpha = smoothstep(p, 0.2, 0.6)
y     = lerp(0, -40dp, p)

---

4.5 topbar morph

t = smoothstep((p - 0.6) / 0.4)

alpha = t
scale = 0.6 + 0.4 * t

---

5. Header System（必须拆出来）

5.1 新建类

ProfileHeaderController.java

public class ProfileHeaderController {

    private View avatar;
    private View name;
    private View actions;

    public void update(float p) {

        float ease = easeOutCubic(p);

        if (avatar != null) {
            avatar.setScaleX(1f - 0.35f * ease);
            avatar.setScaleY(1f - 0.35f * ease);
            avatar.setTranslationY(-120 * ease);
        }

        if (name != null) {
            name.setAlpha(smoothstep(p));
        }

        if (actions != null) {
            actions.setAlpha(1f - p);
        }
    }
}

---

5.2 为什么必须拆

因为 Telegram 的本质是：

Header = independent rendering layer

不是 RecyclerView item

6. TopBar System（吸附动画核心）

6.1 作用

实现：

header → topbar identity morph

---

6.2 代码

public class ProfileTopBarController {

    private View avatar;
    private View title;

    public void update(float p) {

        float t = smoothstep((p - 0.6f) / 0.4f);

        if (avatar != null) avatar.setAlpha(t);
        if (title != null) title.setAlpha(t);
    }
}

---

6.3 为什么这样做

不是“移动”，而是：

crossfade + layered replacement

7. Scroll Engine（统一入口）

7.1 必须改造 onScroll

private float collapseDistance = 300f;
private float p = 0f;

@Override
public void onScroll(int scrollY) {

    p = Math.max(0f, Math.min(1f,
        scrollY / collapseDistance
    ));

    headerController.update(p);
    topBarController.update(p);
}

---

7.2 为什么必须统一 p

因为 Telegram 的 UI 本质：

single-variable driven UI system
